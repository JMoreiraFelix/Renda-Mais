# Renda-Mais
Organizador de Declaração de Imposto de Renda


# Controle de Entradas e Informes de Rendimentos
Este projeto consiste em uma ferramenta desenvolvida em Excel para auxiliar o usuário no gerenciamento de suas finanças pessoais e organização de dados para a declaração de Imposto de Renda. O arquivo foi estruturado para ser intuitivo, dinâmico e adaptável à realidade de cada investidor ou contribuinte. 


# 🎯 Objetivo do Projeto
O objetivo principal é permitir que o usuário tenha um controle centralizado de suas entradas financeiras. A planilha serve como um repositório organizado para consolidar informações que, costumeiramente, ficam espalhadas em diversos informes de rendimentos bancários. 


# Automação de Bancos
Diferente de uma planilha estática, foi adicionada uma automação que permite ao usuário personalizar a seção de informes conforme sua necessidade real:

- Adicionar Bancos: Através de um botão dedicado, o usuário pode inserir novos blocos de campos (Banco, Valor Atual e Anexo) automaticamente, mantendo a formatação original. 
- Remover Bancos: Caso o usuário encerre uma conta ou não precise de um bloco específico, é possível removê-lo com um clique, garantindo que a planilha permaneça limpa e organizada. 

Flexibilidade: Essa funcionalidade garante que a ferramenta seja escalável, funcionando tanto para quem possui conta em apenas um banco quanto para quem possui diversas fontes de rendimento.
